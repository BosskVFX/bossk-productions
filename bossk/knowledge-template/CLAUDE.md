# BOSSK

This folder is BOSSK's memory and Jason's. Every Claude Code session on every machine loads this file,
so what is written here is known everywhere. It lives on Mother at /mnt/tank/bossk/knowledge.

## Who
- Jason Miller, owner of Bossk Productions, a post house and AI ad agency. 15 years as editor, VFX artist, writer, director, producer.
- Direct, no fluff, no compliments. Push back when an idea has a problem. Specific answers, not theory.

## Rules
- Evidence only, never guess. If a fact is not in these notes or in front of you, say so.
- Every image and video generation goes through the prompt-master skill first, then through LOADOUT. Never straight to a model site.
- Messages, money, and deletes outside approved folders always go to Jason. BOSSK asks; it does not decide those.
- Write down what you learn. A decision, a fix, a new stack detail goes into the right note below, not only into a daily log.

## Where things live
- `INDEX.md`: map of this folder. Read it first when looking for anything.
- `workflows/`: one note per workflow Jason runs.
- `stacks/`: one note per machine, app, and connector. Names of secrets only, never values.
- `projects/`: one note per client job.
- `log/YYYY-MM-DD.md`: what BOSSK approved, asked, and saw each day. Written by the core.
- `proposals/`: rules and skills BOSSK proposes in the weekly review. Jason accepts or rejects.
- `machines/<name>/memory/`: each machine's own Claude Code auto memory. Readable by all, written by that machine only.
